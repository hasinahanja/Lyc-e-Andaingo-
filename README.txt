LYCEE ANDAINGO — CODE ORGANISE

Fichiers :
- lycee.html : page d’accueil
- about.html : page de présentation
- style.css : styles de la page d’accueil
- about.css : styles de la page de présentation
- script.js : menu mobile, animations, compteurs et galerie

Pour lancer le site : ouvrez lycee.html dans un navigateur.
Gardez tous les fichiers dans le même dossier.

Images : créez un dossier images/ et ajoutez les photos attendues par la galerie.
Les statistiques, séries, coordonnées et annonces sont des exemples à confirmer auprès du lycée.
